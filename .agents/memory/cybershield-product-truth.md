name: Cybersecurity product truth
description: Truthfulness constraints for public cybersecurity product content.
---

The cybersecurity platform is under development. Do not fabricate scan results, threat intelligence, malware detection, API responses, security scores, investigation speed, success rates, or reports. If a capability is not connected to a real backend, label it Demo, Simulation, Preview, or Planned. Do not claim active device protection unless implemented and tested.

**Why:** the user stated this explicitly in the product brief.

**How to apply:** keep sample console activity visibly simulated, roadmap items marked as planned, and performance metrics as placeholders or sourced results.
